# API.md

# API Specification

---

# Upload Bid Excel

POST

```text
/upload-bid-excel
```

Purpose:

Upload Excel and parse bid records.

---

# Import Records

GET

```text
/import-records
```

Purpose:

Query staging records.

---

# Export Records

GET

```text
/export-import-records
```

Purpose:

Export records to Excel.

---

# Review Records

POST

```text
/review-import-records
```

Purpose:

Approve or reject records.

---

# Sync Records

POST

```text
/sync-import-records
```

Purpose:

Sync approved records into bid_records.
